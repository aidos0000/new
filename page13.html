4.4.DNS (Domain Name System):

DNS (Domain Name System) — бұл интернетте домен аттарын (мысалы, google.com) IP мекенжайларына (мысалы, 172.217.5.78) ауыстыруды қамтамасыз ететін жүйе. DNS интернеттің «телефон кітапшасы» деп те аталады, себебі ол адамдарға таныс домен аттары мен олардың сәйкес келетін IP мекенжайларын табуға мүмкіндік береді. Интернетке қосылған кез келген құрылғыға дұрыс байланыс орнату үшін IP мекенжайы қажет болады, ал DNS осы ауысымды автоматты түрде орындайды.

DNS жұмыс принципі:

  1. Домен атын іздеу (Resolution):

    • DNS сұрауы интернетке қосылған құрылғыдан (клиенттен) домен атын іздеу кезінде пайда болады. Бұл сұрау веб-серверге жіберіледі, және DNS оны IP мекенжайына ауыстырады.

    • Мысалы, пайдаланушы браузерге www.example.com деп жазғанда, браузер DNS серверіне сұрау жіберіп, осы доменнің IP мекенжайын сұрайды.

  2. DNS серверінің рөлі: DNS сұрауы белгілі бір DNS серверіне жіберіледі, ол сұралған домен атын IP мекенжайына ауыстырады. DNS жүйесі бірнеше деңгейлі құрылымнан тұрады:

    • Тамыр DNS серверлері (Root DNS servers): Олар жоғары деңгейлі серверлер болып табылады және домендер мен олардың қатысушы серверлерінің тізімін сақтайды.

    • Тұқым (Top-Level Domain, TLD) серверлері: Бұл серверлер жоғары деңгейдегі домендерді басқаруды қамтамасыз етеді. Мысалы, .com, .org, .net, .edu, .gov және басқа TLD домендер.

    • Авторизацияланған DNS серверлері: Әрбір домен үшін нақты ақпарат сақталатын серверлер. Олар нақты домендерге қатысты мәліметтерді ұсынады, мысалы, www.example.com үшін оның IP мекенжайы.

  3. DNS сұрау процесі:

    • Клиент DNS серверіне сұрау жібереді: Пайдаланушы веб-сайтты аша бастағанда, оның браузері DNS серверіне www.example.com деген сұрау жібереді.

    • Тамыр серверінен бастап сұрау: Тамыр сервері бастапқы сұрауды қабылдап, оны сәйкес TLD серверіне жібереді (мысалы, .com домені үшін).

    • TLD сервері сұрауды бағыттайды: TLD сервері сұрауды тиісті авторизацияланған DNS серверіне жібереді.

    • Авторизацияланған DNS сервері жауап береді: Бұл сервер нақты доменнің IP мекенжайын береді.

    • IP мекенжайы клиентке қайтарылады: Браузер серверден алынған IP мекенжайына сұрауды жібереді және сол IP мекенжайы бойынша веб-сайтты жүктейді.

DNS компоненттері:

  1. Домен аттары:

    • Домен аты — бұл компьютер немесе серверге арналған адамға оқуға ыңғайлы атау. Мысалы, www.google.com.

    • Домен аттары иерархиялық түрде құрылымданған: ең жоғары деңгейдегі домен (тамыр) -> TLD (мысалы, .com, .org) -> екінші деңгейлі домен (мысалы, google) -> үшінші деңгейлі домен (мысалы, www).

  2. DNS жазбалары: DNS серверлері әртүрлі түрдегі жазбаларды сақтайды. Әр жазба белгілі бір ақпаратты ұсынады:

    • A жазбасы (Address Record): Домен атын IP мекенжайына ауыстыру үшін қолданылады. Мысалы, www.example.com үшін A жазбасында IP мекенжайы көрсетіледі.

    • CNAME жазбасы (Canonical Name Record): Бір домен атын басқа домен атына бағыттайды. Мысалы, www.example.com мен example.com бір серверге бағытталса, онда CNAME жазбасын қолдануға болады.

    • MX жазбасы (Mail Exchange Record): Бұл жазба электрондық пошта серверінің орналасқан жерін көрсетеді. Егер сіздің доменіңіз электрондық пошта қызметін пайдаланатын болса, MX жазбасы көрсетіледі.

    • NS жазбасы (Name Server Record): Доменнің DNS серверінің орналасқан жерін көрсетеді.

    • TXT жазбасы (Text Record): Домен үшін қосымша ақпаратты сақтауға арналған. Бұл жазба кейде қауіпсіздік мақсатында пайдаланылады.

DNS кэштеу:

DNS серверлері сұрауларды жеделдету үшін кэштеу механизмін пайдаланады. Бұл дегеніміз, егер домен аты үшін сұрау бұрын жасалған болса, сервер бұрынғы жауапты сақтап, қайтадан сұраудың қажеті жоқ. Әрбір DNS жазбасы үшін белгілі бір уақыт ішінде жарамдылық мерзімі болады. Бұл мерзім TTL (Time To Live) деп аталады.

DNS қауіпсіздігі (DNSSEC):

DNS-тің қарапайым протоколы қауіпсіздік мәселелеріне ұшырай алады, өйткені DNS жауаптарын өзгерту немесе қолданушыларды жалған серверлерге бағыттау мүмкін. Осыған байланысты DNSSEC (DNS Security Extensions) жүйесі енгізілген. Бұл жүйе DNS жауаптарының шынайылығын тексеруді қамтамасыз етеді, яғни жауаптың өзгермегеніне кепілдік береді.

DNS артықшылықтары:

  1. Қолданушыға ыңғайлы: Адамдарға IP мекенжайларын есте сақтаудың орнына таныс домен аттарын пайдалану оңай.

  2. Шешілетін сұраулардың тиімділігі: DNS серверлері сұрауларды кэштеуді қолдайды, бұл сайттардың жүктелу уақытын қысқартуға көмектеседі.

  3. Бірнеше серверлердің қолдауымен жоғары қолжетімділік: DNS бірнеше серверлер арқылы жұмыс істейді, сондықтан серверлердің бірі істен шықса, басқа серверлер автоматты түрде сұрауларды өңдей алады.

DNS кемшіліктері:

  1. Қауіпсіздік тәуекелдері: DNS серверлері хакерлердің шабуылдарына ұшырауы мүмкін. Мысалы, DNS spoofing немесе cache poisoning сияқты шабуылдар арқылы қолданушыларды жалған веб-сайттарға бағыттауға болады.

  2. Қиындықтар: DNS дұрыс жұмыс істемеген жағдайда веб-сайттарға қосылу қиын болады. Мысалы, серверде ақау болса немесе жазба жаңартылмаса, сайтқа кіре алмау мүмкін.

DNS қолдану салалары:

  1. Веб-сайттар: DNS интернеттің барлық веб-сайттарының жұмыс істеуін қамтамасыз етеді. Әр веб-сайттың бірегей домен аты мен оған сәйкес IP мекенжайы болады.

  2. Электрондық пошта: Электрондық пошта қызметтерінде MX жазбалары арқылы пошта серверлері анықталады, бұл электрондық пошта хабарламаларының дұрыс бағытталуына мүмкіндік береді.

  3. Желіде тіркелген құрылғылар: DNS серверлері ішкі және сыртқы желілерде құрылғылардың өзара байланысын жеңілдетуге көмектеседі.

Қорытынды:

DNS — интернеттің маңызды бөлігі болып табылады, өйткені ол домен аттарын IP мекенжайларына ауыстыруды қамтамасыз етеді. Бұл процесс веб-сайттардың дұрыс жұмыс істеуі үшін маңызды, сондай-ақ оны тиімді әрі жылдам етеді. DNS қауіпсіздігі мен басқарылуы дұрыс орнатылған жағдайда оның жұмысын сенімді және қауіпсіз етуге болады.
