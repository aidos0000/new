4.5.DHCP (Dynamic Host Configuration Protocol):

DHCP (Dynamic Host Configuration Protocol) — бұл компьютерлік желіде құрылғыларға автоматты түрде IP мекенжайларын, субнет маскаларын, шлюздерді және басқа да желілік параметрлерді тағайындайтын хаттама. DHCP динамикалық түрде желіге қосылған құрылғыларға қажетті конфигурацияларды қамтамасыз етеді, бұл желі әкімшісінің жұмысын жеңілдетеді және желіге құрылғылар қосылуын жылдамдатады.

DHCP қалай жұмыс істейді:

  1. Құрылғының қосылуы:

    • Жаңа құрылғы (мысалы, компьютер, смартфон немесе басқа құрылғы) желіге қосылады және ол DHCP серверінен өзіне қажетті конфигурацияны алу үшін сұрау жібереді.

  2. DHCP Discover:

    • Құрылғы желіге қосылған кезде DHCP Discover деп аталатын арнайы сұрау хабарламасын жібереді. Бұл хабарлама желідегі барлық DHCP серверлеріне бағытталады.

  3. DHCP Offer:

    • DHCP сервері бұл сұрауға жауап ретінде құрылғыға өзінің ұсынысын жібереді. Ол ұсыныс құрылғыға IP мекенжайын, субнет маскасын, шлюз мекенжайын және басқа да қажетті желілік параметрлерді қамтиды.

  4. DHCP Request:

    • Құрылғы алған ұсыныстардың ішінен бірін таңдап, серверге DHCP Request хабарламасын жібереді. Бұл хабарлама құрылғының қай DHCP серверінен ұсыныс қабылдағанын растайды.

  5. DHCP Acknowledge:

    • DHCP сервері құрылғыға оның сұрауы қабылданғанын және көрсетілген параметрлердің тағайындалғанын растау үшін DHCP Acknowledge хабарламасын жібереді.

  6. IP мекенжайын пайдалану:

    • Құрылғы бұл кезеңнен кейін желіде жұмыс істеу үшін тағайындалған IP мекенжайын пайдалана бастайды.

DHCP жұмыс принципі (қадамдар):

  1. Құрылғының қосылуы (DHCP Discover):

    • Жаңа құрылғы DHCP серверінен IP мекенжайын алу үшін арнайы хабарлама жібереді.

  2. Сервердің ұсынысы (DHCP Offer):

    • DHCP сервері құрылғыға IP мекенжайын және басқа желілік параметрлерді ұсынады.

  3. Құрылғының таңдау жасауы (DHCP Request):

    • Құрылғы DHCP серверінен ұсынылған IP мекенжайын қабылдайтынын хабарлайды.

  4. Сервердің растауы (DHCP Acknowledge):

    • DHCP сервері құрылғыға IP мекенжайының берілуін растайды.

DHCP қолдану үшін қажетті компоненттер:

  1. DHCP сервері:

    • DHCP қызметін ұсынатын сервер немесе құрылғы. Ол желіге қосылатын құрылғыларға динамикалық түрде IP мекенжайлары мен басқа конфигурацияларды тағайындайды.

  2. DHCP клиенті:

    • Желідегі құрылғы (компьютер, телефон, принтер және т.б.), ол DHCP серверінен автоматты түрде желі параметрлерін алу үшін сұрау жібереді.

  3. DHCP релелі (Relay):

    • DHCP сұрауларын бір желіден екінші желіге жеткізетін құрылғы немесе сервер. Егер DHCP сервері желіде басқа сегментте орналасса, релейлер бұл сұрауларды дұрыс бағыттауға көмектеседі.

DHCP-тің артықшылықтары:

  1. Автоматизация:

    • Желідегі құрылғылардың IP мекенжайларын автоматты түрде тағайындау уақытты үнемдейді және желі әкімшілерінің жұмысын жеңілдетеді. Әр құрылғы үшін қолмен IP мекенжайын тағайындаудың қажеттілігі жойылады.

  2. IP мекенжайларының тиімді басқарылуы:

    • DHCP сервері IP мекенжайларын орталықтан басқаруға мүмкіндік береді. Бұл IP мекенжайларын қайта пайдалану, сондай-ақ IP мекенжайларын бөлу мен қайтару жұмыстарын оңтайландырады.

  3. Ақауларды азайту:

    • DHCP жүйесі арқылы дұрыс IP мекенжайлары мен басқа да конфигурацияларды автоматты түрде алу құрылғылардың желіге дұрыс қосылуын қамтамасыз етеді және желі қателерінің алдын алады.

  4. Икемділік:

    • DHCP сервері динамикалық түрде IP мекенжайларын тағайындайды, сондықтан желіге қосылған құрылғылардың саны өзгерсе де, сервер қажет болған жағдайда жаңа мекенжайларды ұсына алады.

DHCP кемшіліктері:

  1. Қауіпсіздік мәселелері:

    • DHCP сервері дұрыс конфигурацияланбаған жағдайда құрылғының желіге қосылуына немесе басқа құрылғыларға қосылуына мүмкіндік беретін қауіпсіздік мәселелері туындауы мүмкін. Мысалы, DHCP Spoofing шабуылы кезінде шабуылдаушы жалған DHCP серверін құрып, құрылғыларды өзіне бағыттай алады.

  2. DHCP серверінің қолжетімсіздігі:

    • Егер DHCP сервері жұмыс істемесе немесе ақаулар болса, құрылғылар IP мекенжайын ала алмайды және желіге қосыла алмайды.

  3. Резервті жүйенің қажеттілігі:

    • Желідегі үлкен көлемде DHCP серверінің жұмысына тәуелділікті ескере отырып, резервті серверлер қажет болуы мүмкін.

DHCP конфигурациясы:

  1. IP мекенжай диапазоны:

    • DHCP сервері құрылғыларға тағайындайтын IP мекенжайларының ауқымын (диапазонын) белгілейді. Мысалы, сервер 192.168.1.100-ден 192.168.1.200-ге дейінгі мекенжайларды құрылғыларға тағайындай алады.

  2. Динамикалық немесе тұрақты тағайындау:

    • DHCP сервері динамикалық IP мекенжайларын ұсына алады, сондай-ақ белгілі бір құрылғыларға тұрақты мекенжайларды (құрылғының MAC мекенжайы арқылы) да тағайындай алады.

  3. Жалдау мерзімі:

    • DHCP сервері әр құрылғыға берілген IP мекенжайының уақытша болуын қамтамасыз етеді. Жалдау мерзімі аяқталған соң, IP мекенжайы қайтадан басқа құрылғыға берілуі мүмкін.

  4. DNS және шлюз параметрлері:

    • DHCP сервері тек IP мекенжайын ғана емес, сонымен қатар DNS серверінің мекенжайы, шлюз (gateway) және басқа желілік параметрлерді де ұсына алады.

DHCP қолдану мысалдары:

  1. Үй желілері:

    • Көптеген үй желілерінде маршрутизатор DHCP сервері болып табылады. Бұл құрылғыларға (компьютерлер, смартфондар, принтерлер) автоматты түрде IP мекенжайларын тағайындайды.

  2. Кәсіби және корпоративті желілер:

    • DHCP корпоративті желілерде де кеңінен қолданылады. Бұл желілерде жұмыс станцияларына, серверлерге, принтерлерге және басқа құрылғыларға автоматты түрде IP мекенжайларын беру жұмысты оңтайландырады.

  3. Wi-Fi желілері:

    • Көптеген Wi-Fi желілерінде мобильді құрылғыларға (телефондар, планшеттер) автоматты түрде IP мекенжайларын тағайындау үшін DHCP қолданылады.

Қорытынды:

DHCP — бұл желі құрылғыларына автоматты түрде IP мекенжайлары мен басқа желілік параметрлерді тағайындау үшін қолданылатын өте пайдалы хаттама. Бұл желі әкімшілеріне жұмысын жеңілдетуге және желіге қосылған құрылғыларды басқаруды оңайлатуға мүмкіндік береді. Бірақ қауіпсіздік тұрғысынан ол кейбір тәуекелдерге ұшырауы мүмкін, сондықтан оны дұрыс конфигурациялау және қауіпсіздік шараларын сақтау маңызды.
