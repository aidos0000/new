4.2.HTTP (HyperText Transfer Protocol):

HTTP (HyperText Transfer Protocol) — бұл веб-беттерді жүктеу және көрсету үшін қолданылатын интернет протоколы. HTTP — әлемдегі ең кеңінен қолданылатын хаттама, ол веб-сервер мен веб-браузер арасында деректерді жіберу үшін жауап береді. Әдетте, HTTP веб-беттерді жүктеу кезінде қолданылатын негізгі хаттама болып табылады.

HTTP-дің негізгі функциялары:

HTTP веб-қосымшалар арасындағы байланыс үшін қолданылатын протокол болып табылады, яғни веб-серверлер мен клиенттердің (әдетте веб-браузерлер) бір-бірімен деректер алмасуына мүмкіндік береді. HTTP қолданушылары веб-беттерді көру үшін URL (Uniform Resource Locator) арқылы сұрау жібереді, ал сервер сол беттерді қолданушының браузеріне жібереді.

HTTP жұмыс принципі:

  1. Клиент-сервер архитектурасы:

    • HTTP негізінен клиент-сервер архитектурасында жұмыс істейді. Клиент — бұл қолданушының браузері немесе басқа құрылғы, ал сервер — бұл веб-қосымшаны немесе веб-сайтты орналастыратын компьютер.

  2. Сұраулар мен жауаптар:

    • HTTP сұрауы: Бұл клиенттен серверге веб-ресурсты сұрау болып табылады. Сұрау HTTP хаттамасы бойынша жіберіледі және оған әртүрлі мәліметтер, мысалы, сұралған ресурс, әдіс, тақырыптар және т.б. кіреді.

    • HTTP жауап: Сервердің клиентке берген жауабы болып табылады. Бұл жауапта сұралған ресурс, мәртебе коды (мысалы, 200 OK немесе 404 Not Found), және басқа да ақпараттар болады.

  3. Статус кодтары: HTTP жауаптарында әрқашан белгілі бір статус кодтары болады. Бұл кодтар сервердің сұрауға қалай жауап бергенін көрсетеді. Мысалы:

    • 200 OK — сұрау сәтті орындалды және сервер жауап ретінде қажетті ақпаратты берді.

    • 404 Not Found — сұралған ресурс серверде табылмады.

    • 500 Internal Server Error — серверде ішкі қате пайда болды.

  4. Қысқа байланыс: HTTP — бұл қысқа байланыс хаттамасы, яғни әрбір сұрау-жауап циклі арасында сервер мен клиент арасында тұрақты байланыс болмайды. Әрбір сұрау жеке байланыс ретінде қарастырылады.

HTTP сұрау түрлері (методтары):

HTTP хаттамасы бірнеше әдістерді (методтарды) қолдайды. Бұл әдістер серверге қандай әрекетті орындау қажеттігін көрсетеді. HTTP сұрауларын жіберу кезінде осы әдістер қолданылып, әрбір сұрау әртүрлі мақсаттарда пайдаланылады:

  1. GET — ресурс алу:

    • Бұл әдіс ең кең тараған HTTP сұрау әдісі болып табылады. Клиент серверден ресурсты (мысалы, веб-бет, сурет, видео) алуды сұрайды.

    • Мысалы: браузерде веб-сайтқа кіргенде, серверге GET сұрауы жіберіледі.

  2. POST — деректерді жіберу:

    • Бұл әдіс серверге деректерді жіберу үшін қолданылады. Ол, әдетте, форма деректерін немесе файлдарды жіберу үшін пайдаланылады.

    • Мысалы: пайдаланушы формада мәліметтерді жібергенде, браузер POST әдісін қолданады.

  3. PUT — ресурсты жаңарту:

    • Бұл әдіс серверде бар ресурсты жаңарту үшін пайдаланылады. Ол серверде бұрыннан бар деректерді толық жаңартуды талап етеді.

    • Мысалы: API арқылы деректерді жаңарту кезінде PUT сұрауы қолданылады.

  4. DELETE — ресурсты жою:

    • Бұл әдіс серверден белгілі бір ресурсты жоюды сұрайды.

    • Мысалы: серверде файлды немесе деректерді өшіру үшін DELETE сұрауы қолданылуы мүмкін.

  5. HEAD — тек тақырыптарды алу:

    • Бұл әдіс серверден тек ресурстың тақырыптарын алу үшін қолданылады, бірақ өзіндік деректері берілмейді.

    • Мысалы: сервердің жай-күйін тексеру үшін қолданылады.

  6. OPTIONS — қол жетімді әдістерді алу:

    • Бұл әдіс сервердің қолдайтын HTTP әдістерін көрсету үшін пайдаланылады.

    • Мысалы: бұл сұрау серверге қандай HTTP әдістерін қолдайтынын білу үшін жіберіледі.

HTTP/HTTPS (Secure HTTP):

  • HTTPS (HyperText Transfer Protocol Secure) — бұл HTTP протоколының қауіпсіз нұсқасы. HTTPS байланыс кезінде деректердің шифрлануын қамтамасыз етеді, яғни клиент пен сервер арасындағы деректер ұрлық немесе өзгерістерге қарсы қорғалған болады.

  • HTTPS қосымшалар мен веб-сайттарда, әсіресе жеке және қаржылық мәліметтерді беру кезінде қолданылады.

HTTP жұмыс циклі:

  1. Сұрау жіберу: Клиент (браузер) серверге сұрау жібереді.

  2. Сервер жауап береді: Сервер сұрауға жауап ретінде деректерді немесе қажетті ресурсты қайтарады.

  3. Клиенттің ресурсты көрсетуі: Браузер немесе басқа клиент ресурсты көрсетеді немесе пайдаланушыға қажет ақпаратты ұсынады.

HTTP және Web Protocols:

HTTP интернетте қолданылатын көптеген қосымша протоколдармен тығыз байланысты. Олардың арасында:

  • DNS (Domain Name System): Веб-сайттың домен атын IP мекенжайына ауыстыру.

  • URL (Uniform Resource Locator): Веб-ресурсты анықтайтын адрес.

  • HTML (HyperText Markup Language): Веб-беттерді құру үшін қолданылатын белгілеу тілі.

HTTP-дің артықшылықтары:

  1. Қарапайымдылық: HTTP жеңіл және қарапайым хаттама болып табылады, өйткені ол клиент пен сервер арасындағы деректер алмасуды тек сұрау-жауап форматында ұйымдастырады.

  2. Қолданудың кең таралуы: HTTP бүкіл әлемде веб-сайттар мен қосымшаларды қолдану үшін негізгі протокол ретінде кеңінен қолданылады.

  3. Платформалық тәуелсіздік: HTTP протоколы платформадан тәуелсіз және түрлі операциялық жүйелер мен құрылғыларда жұмыс істей алады.

HTTP-дің кемшіліктері:

  1. Қауіпсіздік: HTTP деректерді шифрламайды, бұл оның қауіпсіздігін төмендетеді, әсіресе жеке немесе қаржылық ақпараттар үшін.

  2. Масштабтылық шектеулері: HTTP протоколы үлкен деректер көлемі мен көптеген сұрауларды өңдеуде тиімділігін жоғалтуы мүмкін.

Қорытынды:

HTTP — веб-беттерді көрсетудің негізі болып табылатын өте қарапайым және тиімді хаттама. Ол интернеттегі барлық веб-сайттардың және веб-қосымшалардың жұмыс істеуін қамтамасыз етеді. Бірақ HTTP-дің қауіпсіздік шектеулері бар, сондықтан маңызды деректермен жұмыс істейтін веб-сайттар HTTPS (Secure HTTP) протоколын пайдаланады.
