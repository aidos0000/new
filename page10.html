4. Торап протоколдары

                                                                                                      4.1.TCP/IP (Transmission Control Protocol/Internet Protocol):

TCP/IP (Transmission Control Protocol/Internet Protocol) — бұл компьютерлік желілерде деректерді жіберу және қабылдау үшін қолданылатын негізгі хаттамалар жиынтығы. Бұл хаттамалар, негізінен, Интернетте және басқа да тораптық желілерде байланыс орнату, деректерді жіберу және алу үшін қолданылады.

TCP/IP негіздері:

TCP/IP екі негізгі протоколдан тұрады:

  1. Transmission Control Protocol (TCP) — Деректерді жеткізу хаттамасы:

    • TCP — сенімді байланыс хаттамасы болып табылады. Ол деректердің жоғалмауын, бұзылмауын және тәртіппен қабылдануын қамтамасыз етеді.

    • TCP деректерді сегменттерге бөліп жібереді және әр сегменттің қабылданғанын тексереді. Егер сегмент жоғалып кетсе немесе қате болса, ол қайта жіберіледі.

    • Бұл протокол байланыс орнатудың, деректердің дұрыс жеткізілуінің және аяқталған соң байланыс аяқталуының барлық кезеңдерін бақылайды.

    • Қолданылатын әрекеттер:

      • Қосылым орнату (handshaking) — TCP қосылымды орнату үшін арнайы қолмен қосу әдісін (3-way handshake) қолданады.

      • Қателерді тексеру — деректерді жібергенде қателерді тексереді және оларды қайта жіберуге мүмкіндік береді.

      • Деректердің бөлінуі мен қайта құрастыруы — деректер сегменттерге бөлініп жіберіледі және олар дұрыс тәртіппен қайта жиналады.

  2. Internet Protocol (IP) — Интернет хаттамасы:

    • IP — деректер пакеттерін бағыттау және жеткізу үшін жауапты протокол. Ол деректерді тораптар арасында дұрыс бағыттау үшін қолданылатын адресацияны орнатады.

    • IP желіде әрбір құрылғыға өзіндік IP адресін тағайындайды және деректер пакеттерін бір компьютерден екінші компьютерге бағыттау үшін қолданады.

    • IP деңгейінде деректердің тасымалдануы мен бағытталуы жүзеге асырылады, бірақ деректердің сенімділігіне кепілдік берілмейді (ол үшін TCP жауапты).

TCP/IP модельі (OSI моделімен салыстырғанда):

TCP/IP моделі өз кезегінде 4 деңгейге бөлінеді, бұл құрылым OSI моделінің 7 деңгейлі құрылымына қарағанда қарапайым әрі ықшам:

  1. Қосылу деңгейі (Link Layer):

    • Бұл деңгей физикалық және деректерді байланыстыру қабаттарымен сәйкес келеді.

    • Оған Ethernet, Wi-Fi сияқты технологиялар жатады, олар деректердің физикалық жіберілуін қамтамасыз етеді.

  2. Интернет деңгейі (Internet Layer):

    • Бұл деңгейде деректер пакеттері IP арқылы бағытталады.

    • IP протоколы деректерді бағыттау үшін, сондай-ақ әрбір құрылғының уникалды IP адресін қолдану үшін жауапты.

  3. Тасымалдау деңгейі (Transport Layer):

    • Бұл деңгейде TCP және UDP (User Datagram Protocol) сияқты протоколдар деректердің тасымалдануын басқаруды қамтамасыз етеді.

    • TCP арқылы деректердің жоғалмауын, дұрыс келуін қамтамасыз етеді, ал UDP кезінде жоғалту немесе қателерге назар аударылмайды, бұл жылдамдықты қажет ететін қосымшалар үшін тиімді.

  4. Қолданушы деңгейі (Application Layer):

    • Бұл деңгейде қолданушының желі арқылы өзара әрекеттесуі орын алады. Бұл деңгейге HTTP, FTP, DNS, SMTP сияқты протоколдар жатады.

    • Бұл деңгейде деректер қолданушыға нақты қызметтерді ұсынады, мысалы, веб-сайттарды қарау (HTTP) немесе файлдарды беру (FTP).

TCP/IP жұмыс принципі:

  1. Деректердің жіберілуі:

    • Деректер TCP протоколы арқылы сегменттерге бөлініп, IP протоколы арқылы бағытталады.

    • Әрбір сегмент үшін бастапқы және мақсатты құрылғылардың IP адресі анықталады.

  2. Қосылым орнату:

    • TCP қосылым орнату үшін «3-ресми қол алысу» әдісін пайдаланады. Бұл процессте екі құрылғы бір-бірімен байланыс орнату үшін бірнеше рет хабарлама алмасады.

  3. Қателерді бақылау:

    • TCP әр сегменттің дұрыс жеткізілгенін тексереді. Егер сегмент жеткізілмесе немесе қате болса, онда ол қайта жіберіледі.

  4. Деректерді бағыттау:

    • IP пакеттерді дұрыс бағыттау үшін әрбір құрылғыға IP адресі тағайындайды және желіде олардың ағынын басқарады.

TCP/IP хаттамасының артықшылықтары:

  1. Интероперабельділік:

    • TCP/IP әлемдегі барлық компьютерлер арасында өзара байланыс орнатуға мүмкіндік береді, өйткені бұл протокол стандартталған және кеңінен қолданылады.

  2. Масштабталуы:

    • Интернетте миллиардтаған құрылғының байланыс орнатуына мүмкіндік береді.

  3. Ашық стандарт:

    • TCP/IP ашық стандарт ретінде барлық құрылғылар мен жүйелер арасында үйлесімділікті қамтамасыз етеді.

  4. Сенімділік:

    • TCP деректердің сенімді жеткізілуін қамтамасыз етеді, бұл сенімді байланыс орнату үшін маңызды.

TCP/IP протоколдарының мысалдары:

  1. HTTP (HyperText Transfer Protocol):

    • Веб-беттерді жүктеу және көрсету үшін қолданылады.

  2. FTP (File Transfer Protocol):

    • Файлдарды компьютерлер арасында беру үшін қолданылады.

  3. SMTP (Simple Mail Transfer Protocol):

    • Электрондық пошта хабарламаларын жіберу үшін қолданылатын хаттама.

  4. DNS (Domain Name System):

    • Домен аттарын IP адресіне ауыстырады, бұл веб-сайттарға қол жеткізу кезінде ыңғайлы болады.

  5. DHCP (Dynamic Host Configuration Protocol):

    • Желіде автоматты түрде IP адресін тағайындайды.

  6. POP3 (Post Office Protocol) және IMAP (Internet Message Access Protocol):

    • Электрондық пошталарды алу үшін қолданылады.

Қорытынды:

TCP/IP — қазіргі заманғы желіде деректерді жіберудің және алудың негізгі хаттамалар жүйесі болып табылады. Оның құрылымы екі маңызды протоколдан тұрады: TCP, ол деректердің сенімді тасымалдануын қамтамасыз етеді, және IP, ол деректерді желіде бағыттауға жауапты. Бұл протоколдар бүкіл әлемдегі құрылғылардың бірігуін қамтамасыз етеді, әрі ол интернеттің негізгі жұмыс істеу принциптерін орнатады.
